# Brouillons, erreurs et diagnostic — 1 octobre 2026

Les formulaires de devis/factures, catalogue, heures, clients/fournisseurs, projets et collaborateurs conservent la saisie localement. La reprise est explicite et séparée par espace, membre, formulaire et document. Une version enregistrée différente impose un choix avant enregistrement. Les fichiers sélectionnés doivent être sélectionnés de nouveau ; leurs octets et les identifiants de connexion ne sont pas conservés dans les brouillons.

Une fermeture conserve la dernière saisie. Un échec d'enregistrement garde le brouillon. Un succès confirmé le termine. Le stockage est borné : 40 saisies, 2 Mo au total, 256 Ko par saisie, expiration de 30 jours. Une indisponibilité de stockage impose un avertissement avant fermeture. Si toutes les écritures et suppressions locales sont refusées, la protection contre la reprise d'une saisie déjà enregistrée ne peut survivre au redémarrage : vérifier le document enregistré avant de recommencer.

Les erreurs ont un message et une consigne en français, allemand, italien et anglais. Les détails techniques sont repliés et expurgés. Les règles métier continuent de recevoir l'erreur originale. Les actions de lecture peuvent actualiser l'affichage ; une mutation incertaine n'est pas rejouée automatiquement.

Le journal local couvre les commandes natives, leur durée/résultat, l'ouverture, la navigation, les transitions de synchronisation, les actions de brouillon et les incidents JavaScript. Aucun argument, résultat métier, texte d'erreur, contenu de document, mot de passe ou clé n'y est écrit. Trois fichiers de 2 Mo maximum tournent dans le dossier privé `diagnostics`. Les écritures sont groupées hors du fil d'interface. Dans Paramètres → Sauvegardes et données → Diagnostic, on peut copier une référence, exporter un journal JSONL ou l'effacer après confirmation. Le partage mobile utilise le dialogue natif existant.

Validation locale : 2 015 tests frontend réussis, 1 test préexistant ignoré ; TypeScript et build de production réussis. Matrice diagnostic : 24 cas de langues/thèmes/tailles, incluant 320 px et texte à 200 %. Toast : 6 cas, fermeture 44 × 44 px, défilement/clavier/copie vérifiés. Parcours de reprise réels des quatre formulaires indépendants testés sur Chromium à 320 et 1 440 px et reprise en quatre langues.

Les tests Rust locaux ont été bloqués par Windows (contrôle d'application, erreur 4551). Le workflow CircleCI de cette branche exécute les tests natifs sur des données synthétiques et ne publie ni n'installe de version. Les changements de ce document ne constituent pas une nouvelle version distribuée ; la version publique reste 1.90.12 jusqu'à une publication distincte.
