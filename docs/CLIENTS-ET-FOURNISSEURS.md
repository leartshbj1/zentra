# Coordonnées et dossier client

## Ajouter un client

Dans **Clients → Nouveau client**, indiquez un nom de contact, une entreprise ou les deux. Pour un particulier, le prénom et le nom suffisent. Complétez l’adresse de facturation : rue, code postal, localité et pays. La Suisse est présélectionnée pour une nouvelle fiche ; choisissez un autre pays si nécessaire. **Autre pays…** permet de saisir un code de deux lettres.

L’e-mail, le téléphone, la région et les notes sont facultatifs. Si un champ doit être corrigé, il reçoit le curseur et une explication. Une erreur d’enregistrement conserve la saisie ; le message complet peut être déplié. Les notes internes ne sont pas ajoutées automatiquement aux documents commerciaux.

Le nom du contact reste distinct de celui de l’entreprise après enregistrement et rechargement. Une entreprise sans contact renseigné ne reçoit pas un contact inventé lors de sa modification. Les documents déjà émis conservent leurs données historiques.

## Retrouver l’activité d’un client

Ouvrez **Dossier** sur la fiche du client. Les coordonnées, les soldes et les projets sont regroupés avec ses devis, factures et avoirs.

- Les documents sont triés par création récente, indépendamment de leur date de facturation.
- La recherche parcourt tout l’historique de ce client. **Afficher plus de documents** donne accès aux documents au-delà des huit premiers.
- **Ouvrir le devis / la facture / l’avoir** ouvre le document. Une facture liée à un devis ouvre le dossier de facturation correspondant.
- Fermer le document revient au dossier client. Après une modification enregistrée ou une visite du projet, **Revenir au dossier client** retrouve les coordonnées actualisées.
- Les consultations restent disponibles en lecture seule ; les enregistrements demandent un accès en écriture.

## Ajouter un fournisseur

Dans **Achats & fournisseurs → Fournisseurs → Nouveau fournisseur**, le nom suffit pour commencer. L’adresse, le contact, l’IDE et l’IBAN sont facultatifs.

Le délai de paiement préremplit les nouveaux achats. Choisissez **Immédiat**, **10 jours**, **30 jours**, **60 jours**, ou saisissez un autre nombre entier de jours. Une décimale ou une valeur négative est signalée sans arrondi automatique.

L’IBAN CH ou LI peut être recopié avec ses espaces. S’il est incorrect, comparez-le à la facture ou laissez le champ vide pour le compléter plus tard. Aucun ordre bancaire n’est envoyé depuis cette fiche.

Après une écriture confirmée suivie d’une lecture interrompue, utilisez **Actualiser les données** : Zentra relit les fiches sans répéter la création.

Ces changements sont intégrés au code. Aucun nouvel installateur ou IPA n’est publié dans ce lot.
