# Utiliser l’agenda Zentra

L’agenda réunit vos rendez-vous et les échéances des projets, devis, factures et salaires. Les vues **Jour**, **Semaine** et **Mois**, les catégories et le bouton **Aujourd’hui** permettent de retrouver la période utile. **Ouvrir** rejoint le document ou le projet à l’origine d’une échéance.

## Ajouter un rendez-vous

Choisissez **Ajouter**, puis renseignez le titre, les dates et les horaires. Le lieu et les notes sont facultatifs. **Projet, responsable et autres options** permet d’associer un projet, d’attribuer le rendez-vous, de choisir son type et son état.

Pour une seule journée, les dates restent identiques quand vous déplacez le début. Si vous avez déjà choisi une période de plusieurs jours, sa fin reste celle que vous avez saisie : une fin antérieure au début demande une correction explicite.

Les boutons **15 min**, **30 min**, **1 h** et **2 h** calculent la fin depuis la date et l’heure de début. Si la durée passe minuit, la date de fin devient le lendemain. Ces boutons remplissent le formulaire sans enregistrer. **Toute la journée** masque les horaires ; décocher l’option retrouve les heures saisies pendant cette édition.

**Enregistrer le rendez-vous** vérifie la saisie. Une date ou une heure incorrecte reçoit une explication au bon champ. Les notes conservent leurs retours à la ligne. Pendant l’enregistrement, la fenêtre et les champs sont protégés ; un refus conserve les informations à corriger.

## Reprendre après une interruption

Après une écriture confirmée suivie d’une lecture interrompue, **Enregistrement effectué → Actualiser les données** relit l’agenda sans sauvegarder une seconde fois. Une nouvelle lecture impossible laisse la reprise ouverte. Elle fonctionne aussi lorsque l’application passe en lecture seule.

La version de chaque rendez-vous protège les modifications et suppressions concurrentes. Si le rendez-vous a changé ailleurs, la saisie reste affichée. Les changements portant sur des informations différentes peuvent être réunis. Pour chaque conflit, choisissez **Ma saisie** ou **Version enregistrée**, puis **Utiliser ces informations**. Les dates et les horaires sont comparés ensemble. Ce bouton prépare le formulaire ; il faut encore le relire et enregistrer. Une version plus récente demande de refaire les choix concernés. Un rendez-vous disparu ne peut pas être écrasé depuis l’ancien formulaire.

## Terminer ou supprimer

**Marquer terminé** ouvre le récapitulatif avant confirmation. Le rendez-vous se retrouve ensuite avec **Afficher terminés / annulés**. Cette action concerne l’agenda ; elle n’enregistre aucun paiement ni aucune validation comptable.

La suppression affiche également le rendez-vous concerné. L’annulation ferme le récapitulatif sans écriture. Si le rendez-vous change entre l’ouverture et la confirmation, **Relire le rendez-vous** présente sa version actuelle avant de permettre la suppression. Le projet et les documents associés sont conservés.

Les actions d’écriture sont désactivées en lecture seule. Les vues, catégories et liens vers les éléments restent consultables.

## Vérification de ce lot

Les recettes utilisent des données synthétiques et la base locale de test. Elles couvrent la création, les erreurs, l’enregistrement interrompu, la comparaison, la finalisation, la suppression et la persistance après rechargement. Les contrôles natifs vérifient les dates, les horaires, l’audit, l’idempotence et le refus des versions anciennes. Aucun calcul financier ni schéma de base ne change. Ce lot ne publie pas de nouvel installateur ou IPA.
