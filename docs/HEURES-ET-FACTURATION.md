# Enregistrer et facturer les heures

Dans **Temps**, choisissez **Saisir des heures**, le projet et le collaborateur. Indiquez les heures entières et les minutes supplémentaires : pour 1 h 30, saisissez 1 et 30. Le temps saisi correspond au travail réellement effectué ; la pause est conservée séparément.

Le coût horaire de l’entreprise se remplit depuis la fiche du collaborateur lorsqu’il est renseigné. Ce coût sert à la rentabilité du projet. Le prix facturé au client est un montant distinct, hors TVA. Une virgule ou un point peut séparer les centimes.

Choisissez **À vérifier** pour enregistrer avant validation, ou **Approuvées** lorsque les heures sont prêtes. Pour les facturer, le projet doit être lié à un client et chaque saisie doit être approuvée, facturable, avec un tarif positif.

Dans **Facturer les heures**, choisissez le projet, décochez les saisies à exclure et vérifiez le résumé. Vous créez une facture brouillon à relire avant son émission. Changer de projet puis revenir conserve votre sélection ; un rafraîchissement ne coche pas de nouvelles heures à votre place.

Les erreurs gardent les informations et dirigent vers le champ à corriger. Pendant un enregistrement, le formulaire reste ouvert et empêche les doubles clics. Si la facture est créée mais que l’actualisation échoue, utilisez la reprise proposée pour relire les données ; l’application ne recommence pas l’écriture.

Le chronomètre utilise les mêmes choix de projet, collaborateur, coût et tarif. Arrêtez-le lorsque le travail est terminé, puis vérifiez les heures créées.
