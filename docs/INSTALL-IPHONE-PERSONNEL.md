# Votre exemplaire iPhone personnel

Cet IPA contient votre licence propriétaire signée. Il est destiné uniquement à votre utilisation et ne doit pas être publié comme téléchargement client.

1. Signez et installez l’IPA avec Sideloadly ou AltStore et votre compte Apple. Le fichier fourni est un IPA pour iPhone physique, sans signature Apple de distribution.
2. Ouvrez Zentra avec une connexion Internet. Sur une installation neuve, votre licence est vérifiée auprès du serveur puis enregistrée dans le stockage protégé de l’iPhone, sans copier de jeton.
3. Configurez l’entreprise et choisissez la langue. Si le réseau est indisponible, rétablissez la connexion et touchez Réessayer.

La licence Zentra ne remplace pas la signature Apple nécessaire pour installer une application. Une identité ou une licence Zentra déjà enregistrée n’est jamais remplacée automatiquement. Le paquet public ne contient aucune licence propriétaire.
