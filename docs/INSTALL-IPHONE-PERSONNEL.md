# Votre exemplaire iPhone personnel

Cet IPA contient votre licence propriétaire signée. Il est destiné uniquement à votre utilisation et ne doit pas être publié comme téléchargement client.

1. Signez et installez l’IPA avec Sideloadly ou AltStore et votre compte Apple. Pour remplacer 1.62.0, installez 1.62.1 par-dessus avec le même compte Apple et le même identifiant d’app. Le fichier fourni est un IPA pour iPhone physique, sans signature Apple de distribution.
2. Ouvrez Zentra avec une connexion Internet. Sur une installation neuve, votre licence est vérifiée auprès du serveur puis enregistrée dans le stockage protégé de l’iPhone, sans copier de jeton.
3. Si l’activation échoue, l’app affiche désormais la cause réelle dans « Activation de votre iPhone ». Le bouton « Activer ma licence personnelle » relance la vérification. L’identifiant de l’iPhone reste visible et copiable.
4. Si le message indique une ancienne identité Zentra différente, transmettez l’identifiant affiché à l’assistance. La licence intégrée reste liée à son identité d’origine ; vos données ne sont pas effacées. Une licence adaptée pourra être installée depuis « Installer une licence fournie par l’assistance ».
5. Choisissez la langue et configurez l’entreprise. Les fonctions qui nécessitent une licence restent protégées jusqu’à une activation réussie.

La licence Zentra ne remplace pas la signature Apple nécessaire pour installer une application. Une identité ou une licence Zentra déjà enregistrée n’est jamais remplacée automatiquement. Le paquet public ne contient aucune licence propriétaire.
