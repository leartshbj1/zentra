# Download — install without the noise

Mode: Operate. Ordinary Studio extension, user-pinned Apple simplicity; code-led.

## Direction contract

THESIS: The user comes to install Zentra. Put Windows and Mac first, with one download each, not a second product brochure.

OWN-WORLD: Existing Geist and forest green; one pearl desktop surface, generous space and restrained separators. No new imagery, decorative installer simulation or sticky phone download dock.

STORY: Choose the computer, download, follow one short instruction. Open a platform-specific tutorial only if blocked. Mobile IPA/APK files come last, with concise honest format labels.

FIRST VIEWPORT: Compact existing navigation, centered Download heading, two desktop platform columns. On phone these stack; full-width touch actions remain clear. Tutorials default closed.

FORM: Local distillation of approved Studio world; no new seed/comp required. Existing installer URLs and versions remain unchanged.

MOTION: Native details disclosure and subtle chevron rotation; reduced-motion support, no automatic motion.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## Removed complexity

Remove duplicate downloads, sales/features sections, backup history, visible checksums, repeated release notes, installer mockup and obsolete simulator highlight. Product pages still carry features/pricing; the GitHub release link keeps access to checksums and other files. Keep concise early-access status, IPA signing/test APK labels, authentic installation guidance and support recovery links. Preserve production auth, billing, app installers and manifests.

## Verification target

Check 1440/768/390/320 layouts, keyboard disclosure, four actual artifact URLs, existing download-contract tests, TypeScript and source build. No installer execution or notarization claim. Guide references: https://support.apple.com/fr-fr/102445 and https://learn.microsoft.com/fr-fr/windows/apps/package-and-deploy/smartscreen-reputation (read 2026-09-24).
